# Contract: Catalog Data API (Amplify Data / AppSync)

**Consumers**: web app (`src/lib/data/`) · **Provider**: `amplify/data/resource.ts`
**Auth mode**: Cognito user pool (`allow.authenticated()`). Every request carries the user's ID/access
token, and requests without a valid token are rejected by AppSync (FR-005).

The GraphQL types are generated by Amplify from the schema. This contract fixes the **operations,
arguments, and behavior** that the front end depends on. Field definitions are in
[data-model.md](../data-model.md#entity-content).

## Schema outline

```text
enum ContentType   { WEBSITE_TEMPLATE POWERPOINT_TEMPLATE VIDEO IMAGE TEXTURE OTHER }
enum ContentStatus { DRAFT PUBLISHED }
enum LicenseType   { REGULAR EXTENDED OTHER UNKNOWN }

model Content            (fields per data-model.md)
  @auth(authenticated: [read])
  @index(bySlug: slug)
  @index(byTypeAndPublishedAt: type, sortKey publishedAt)

type DownloadUrl { url: AWSURL!, expiresAt: AWSDateTime! }

query getDownloadUrl(contentId: ID!): DownloadUrl
  @auth(authenticated)  @function(get-download-url)
```

No mutations or subscriptions are exposed. The model's default `getContent` and `listContents`
queries are disabled with `.disableOperations([...])` (research R4), so the only way to read the
catalog is through the two index queries below.

## Operations

### 1. List a browse row

`listContentByTypeAndPublishedAt(type: ContentType!, sortDirection: DESC, limit: Int, nextToken: String)`

| Aspect | Contract |
|---|---|
| Page size | Client sends `limit: 20` for rows and `limit: 60` for "See all" |
| Order | Newest `publishedAt` first |
| Contents | **Published items only**, guaranteed by the sparse index |
| Selection set | `id slug title type thumbKeys` (cards need nothing more) |
| Pagination | Returns `nextToken`. A `null` `nextToken` means the end |
| Empty | `items: []`. The client hides the row (FR-007) |

The browse page issues one call per `ContentType`, in parallel.

### 2. Get an item by slug

`listContentBySlug(slug: String!)`

| Aspect | Contract |
|---|---|
| Result | 0 or 1 item. More than 1 is a data error: the client uses the first and logs a warning |
| Draft handling | If `status !== 'PUBLISHED'`, the client renders not-found (FR-016) |
| Selection set | All `Content` fields except `archiveKey` |

### 3. Get a download URL

`getDownloadUrl(contentId: ID!) → DownloadUrl`

| Step | Behavior |
|---|---|
| Identity | Email comes from the AppSync identity claims. A missing or non-`example.com` email → `Unauthorized` |
| Lookup | `Content` by `id`. Missing or not `PUBLISHED` → `NotFound` |
| Logging | `DownloadEvents` put + `downloadCount ADD 1`, run concurrently. A failure is logged to CloudWatch and **doesn't fail the request** |
| Response | `url` = CloudFront signed URL for `https://assets.example.com/<archiveKey>` (canned policy). `expiresAt` = now + 300 s |
| Client action | `window.location.assign(url)`. The browser downloads with the `Content-Disposition` filename |

**Errors** (GraphQL `errors[].errorType`):

| errorType | When | Client UX |
|---|---|---|
| `Unauthorized` | No session or wrong domain | Redirect to `/` |
| `NotFound` | Unknown or unpublished id | Toast: "This item is no longer available." |
| `ArchiveMissing` | `HeadObject` on `archiveKey` returns 404 | Toast: "The file for this item is missing. Please let the owner know." (logged as an error in CloudWatch) |
| `InternalError` | Anything else | Toast: "Download failed. Please try again." |

**Performance**: p95 < 500 ms warm (NFR-2). The handler caches SSM values for the life of the
container.
